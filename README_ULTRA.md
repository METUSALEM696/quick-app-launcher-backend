## 📦 **DEPENDENCIES (Auto-Installed):**

The script automatically installs these if missing:

1. **colorama** - Terminal colors (basic fallback)
2. **rich** - Advanced UI, tables, panels, progress bars
3. **psutil** - System monitoring (CPU, RAM, Disk)

**Fallback Strategy:**
- If `rich` unavailable → Uses `colorama` only
- If `colorama` unavailable → Plain text mode
- If `psutil` unavailable → No system stats
- **Everything still works!** Just less fancy.

## 🐛 **TROUBLESHOOTING:**

### **Issue: "Administrator privileges required"**
**Solution:** Use `START_MANAGER_ADMIN.bat` for auto-elevation

### **Issue: "Python not found"**
**Solution:** 
1. Open CMD
2. `python --version`
3. If fails → Add Python to PATH

### **Issue: Libraries not installing**
**Solution:**
```bash
python -m pip install colorama rich psutil --break-system-packages
```

### **Issue: No colors showing**
**Solution:** Libraries failed to install, but script still works in plain text mode

### **Issue: No sound**
**Solution:** 
- Check Settings [9] → Sound enabled?
- Windows only feature (uses winsound)
